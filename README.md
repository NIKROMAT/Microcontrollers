## Микроконтроллер: 
1882BE53Y(AT89S8253)

## Условия:
Сравнение двух чисел в десятичном коде
### Ввод:
Мини-клавиатура  - до 5 символов 0..9, “ввод” 
Клавиатура ПК – до 5 символов 0..9. “enter” 
### Вывод:  
результат сравнения: больше, меньше, равно.
все вводимые символы должны отображаться на 2хстрочном LCD-дисплее.
